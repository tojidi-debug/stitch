# ECOS2 통계 조회 대시보드 설계

## 목표

기존 `ecos.html`과 동일한 화면 밀도와 사용 흐름을 유지하면서 주가지수, 경제성장률, 수출물가지수, 수입물가지수, 생활물가지수, 국내공급물가지수를 조회하는 단일 페이지 `ecos2.html`을 제공한다. ECOS API 키는 공개 페이지에 포함하지 않으며 기존 GitHub Actions 비밀값 하나를 재사용한다.

## 사용자 경험

- 첫 화면 상단에 단일 조회일/기간 조회, 전체 조회, Clear, 전체 엑셀 다운로드, 관리자 설정 버튼을 둔다.
- 본문은 기존 사이트와 같은 2열 카드형 화면으로 구성한다.
- 각 카드에는 세부 항목 체크박스, 요약값, 추세 차트, 가로 스크롤 표, COPY, 개별 엑셀 다운로드, 조회 버튼을 둔다.
- 결과 표는 일자가 열 방향으로 놓이고 최신일자가 보이도록 처음부터 오른쪽 끝에 위치한다.
- 화면이 좁으면 카드가 한 열로 바뀌며 상단 조회 도구는 줄바꿈된다.

## 기본 통계 묶음

1. 주가지수
2. 경제성장률
3. 수출물가지수·수입물가지수
4. 생활물가지수
5. 국내공급물가지수

정확한 ECOS 통계표 코드, 항목 코드, 주기는 공개 데이터 카탈로그에 기록한다. 경제성장률을 위해 분기 주기를, 필요한 경우 연간 주기도 지원한다.

## 관리자 설정

관리자 설정은 같은 페이지 안의 접이식 패널로 제공한다. 사용자는 공개 카탈로그에 포함된 통계 묶음을 추가하거나 숨기고, 순서를 바꾸고, 표시 명칭과 기본 선택 항목을 바꿀 수 있다. 설정은 `localStorage`에 저장되므로 해당 브라우저에만 적용된다. 기본값 복원과 설정 내보내기/가져오기를 제공한다.

GitHub Pages는 정적 호스팅이므로 관리자 설정을 모든 방문자에게 즉시 적용하거나 ECOS에서 임의의 새 통계를 비밀키로 가져올 수 없다. 공개 기본 목록을 바꾸려면 저장소의 카탈로그와 데이터 수집 설정을 변경해 다시 배포한다.

## 데이터 및 보안

- GitHub Actions가 `ECOS_API_KEY` 저장소 비밀값으로 ECOS 데이터를 수집한다.
- 수집 결과는 `public/ecos2-data/*.json`과 `manifest.json`으로 생성한다.
- 브라우저는 같은 GitHub Pages 출처의 JSON만 읽는다.
- HTML, JavaScript, 네트워크 요청 및 소스 보기에는 API 키가 포함되지 않는다.
- 데이터가 없거나 발표 전이면 오류 대신 발표 시차 안내를 보여준다.

## 엑셀

- 개별 카드와 전체 통합 파일을 다운로드할 수 있다.
- 표와 동일하게 첫 열은 항목명, 이후 열은 일자별 값으로 만든다.
- 주가지수, 성장률, 수출입물가, 생활물가, 국내공급물가처럼 짧고 명확한 시트명을 사용한다.
- 차트는 실제 시트 셀을 참조하며, 축 간격과 범례를 데이터 양에 맞게 조정한다.

## 검증

- 일·월·분기·연간 기간 변환과 필터링
- 관리자 설정 저장, 복원, 가져오기 및 잘못된 설정 거부
- 카드 표시/숨김과 순서 변경
- 최신일자 방향 자동 스크롤
- 개별/전체 엑셀의 시트명, 행열 방향, 차트 셀 참조
- GitHub Pages 하위 경로에서 정적 자산과 데이터 요청 성공
